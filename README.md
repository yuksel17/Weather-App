# 🌤️ Weather App

Weather App, **SwiftUI** kullanılarak geliştirilen modern bir iOS hava durumu uygulamasıdır. Uygulama, kullanıcıların şehir adına göre hava durumu sorgulamasına veya harita üzerinden konum seçerek güncel hava durumu bilgilerine ulaşmasına olanak tanır. Hava durumu verileri **OpenWeather API** üzerinden alınarak kullanıcı dostu bir arayüzde sunulmaktadır.

---

## 🚀 Özellikler

- 🔍 Şehir adına göre hava durumu arama
- 🗺️ Harita üzerinden konum seçebilme
- 🌡️ Anlık sıcaklık bilgisi
- ☁️ Hava durumu açıklaması ve ikonu
- 💧 Nem oranı
- 🌡️ Hissedilen sıcaklık
- 🎨 Hava koşullarına göre otomatik değişen arka plan
- 📱 Modern ve kullanıcı dostu SwiftUI arayüzü
- 🏛️ MVVM (Model-View-ViewModel) mimarisi

---

## 🛠️ Kullanılan Teknolojiler

- Swift
- SwiftUI
- MVVM
- MapKit
- CoreLocation
- URLSession
- OpenWeather API

## ⚙️ Kurulum

1. Bu repoyu bilgisayarınıza klonlayın.

```bash
git clone https://github.com/yuksel17/Weather-App.git
```

2. Projeyi Xcode ile açın.

```text
Weather App.xcodeproj
```

3. OpenWeather API üzerinden ücretsiz bir API anahtarı oluşturun.

4. API anahtarınızı `WeatherService.swift` dosyasındaki ilgili alana ekleyin.

5. Projeyi çalıştırın.
